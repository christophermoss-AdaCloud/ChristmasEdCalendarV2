# 🎄 Christmas Educational Advent Calendar

A beautiful, interactive static website featuring an educational advent calendar with 25 days of Christmas-themed learning content.

## Features

- **Interactive Advent Calendar**: 25 days of educational content about Christmas traditions, science, history, and culture
- **Beautiful Design**: Modern, responsive design with festive Christmas theme
- **Animated Snowflakes**: Falling snow animation for atmosphere
- **Daily Unlocking**: Days unlock progressively (in December) or all available for demonstration
- **Progress Tracking**: Uses localStorage to remember which days have been opened
- **Mobile Responsive**: Works perfectly on all device sizes

## How to Use

1. **View Locally**: Simply open `index.html` in any modern web browser
2. **Click on Days**: Click any unlocked day (1-25) to view educational content
3. **Read & Learn**: Each day contains interesting facts and information about Christmas-related topics
4. **Track Progress**: Days you've opened will show a checkmark

## Topics Covered

The calendar includes educational content about:
- Christmas history and traditions
- Science (snow, weather, biology)
- Music and literature
- Global celebrations
- Physics and chemistry
- Psychology and cultural studies

## Technical Details

- **Pure HTML/CSS/JavaScript**: No frameworks or dependencies required
- **Static Website**: Can be hosted anywhere (GitHub Pages, Netlify, etc.)
- **Local Storage**: Saves progress across browser sessions
- **Responsive Design**: Mobile-first approach with breakpoints for tablets and desktop

## Deployment

### GitHub Pages
1. Push to GitHub repository
2. Go to Settings → Pages
3. Select branch and folder
4. Your site will be available at `https://[username].github.io/[repo-name]`

### Other Hosting
Simply upload all files to any web server or static hosting service:
- Netlify
- Vercel
- AWS S3
- Any web hosting with static file support
